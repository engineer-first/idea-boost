# 参加者の顔アイコン

PBI #750 / Task #869 の採用案「Soft Pop Crew」を参照し、組込みの Image Gen で1人ずつ生成した20種類の素材。

- ファイル: `face-01.webp` ～ `face-20.webp`
- 形式: 256×256px、背景透過 WebP。顔と肩だけを含む。
- 背景: 画像へ焼き込まず、参加者本人の付箋色を表示側で適用する。
- 表示: 待機画面・参加者一覧・発表者などで共通利用する。名前と接続・完了状態は画像と別に表示する。

生成指示は、採用した人物ごとの髪型・表情・服装を保持し、丸いマットな3D調、正面中心、1画像1人、文字・背景・枠なしとした。原寸PNGから縦横比とアルファを保って縮小・WebP化している。
