# 工程別の操作動画

`step-1-2.webm`・`step-1-3.webm`・`step-1-4.webm`・`step-1-5.webm`・`step-3-3.webm` は、2026-10-27にローカル検証環境の実ボードをPlaywrightから操作して撮影した動画です。Storybookの模擬操作や図解アニメーションではありません。

- 確認用環境とは別のアプリ・Workerポートと保存先を使い、既存ルームの解散・変更を避けます。撮影環境のサンプルルームだけを操作します。
- 共有はViewer本人の画面で前の人の発表を待ち、自分の番になってからマイ付箋を共有し、発表後に「次の人へ」で交代する流れです。整理は未分類の付箋どうしのグループ作成と名前変更、投票は貼付と取消、決定は選択開始と採用、評価は2軸マップ内の移動を撮影します。
- カーソルの輪と押下時の黄色は撮影用の補助表示です。アプリ本体の機能ではありません。
- 操作箇所を追うカメラで切り取り、動画枠に合わせた960×300で書き出しています。素材の縦横を同じ倍率で拡大し、左右の余白を埋めるための引き伸ばしはしません。音声は含みません。
- スライドでは既存の図解枠に `object-contain` で表示し、スライド寸法を動画に合わせて変えません。

既存の `operation-guide-placeholder.webm` は1-1用の仮素材であり、この5本とは別です。
