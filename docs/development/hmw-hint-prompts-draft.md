## 方向性

現在の問いかけは「課題を HMW に変換する」発想で `{issue}` を埋め込む形。行動・習慣系の課題（例: 朝起きれない）に噛み合わないため、**インタビュー形式（課題を分解する質問）**に切り替え、課題の種類（ジャンル）に応じて質問を変える。

決定課題はバナーで別表示されるため、問いかけ側は課題文を必ず含めなくてよい。

## ジャンル分類（4組 × 3語 = 12語を維持）

| ジャンル      | 対象例                                       |
| ------------- | -------------------------------------------- |
| A. 行動・習慣 | 朝起きれない、勉強が続かない、片付けられない |
| B. 場所・環境 | 集中できない、移動が大変、騒音が気になる     |
| C. 人・関係   | 相談できない、チームで揉める、頼みにくい     |
| D. 時間・負担 | 時間がない、疲れやすい、忘れる               |

## 方針更新（部分変更）

ユーザー指示: 以下の5つの問いかけ**以外**は現行の内容をそのまま運用する。

- ○○に関係する場所を変えたら、何が変わるだろう → 置き換え
- そもそも○○はなぜ困るのだろう？ → 置き換え
- ○○について、別の人の立場では何が変わるだろう？ → 置き換え
- どうしたら、○○という困りごとを解消できるだろう → 置き換え
- ○○に関係する行動や仕組みを別のものに置き換えたら、何が変わるだろう？ → 置き換え

## 仕様上の変更点（実装時）

1. 置き換え対象の5件は `{issue}` を含まないインタビュー形式。それ以外の7件は現行どおり `{issue}` を含む。`buildHmwHintQuestion` はプレースホルダが無ければそのまま返す。
2. 課題が空でもインタビュー質問は表示可能にする。
3. `HMW_TEMPLATES`（修飾語5つ）は別系統、今回触らない。
4. ジャンルはランダム選択のまま。課題文からの自動推定はスコープ外。
5. 既存テスト（`hmw-hints.spec.ts`）の期待値更新が必要。

## 決定更新（2026-11-11）

呼びかけは「こんな問い方も / あるかも...」に決定（旧: こんな見た目も）。

上記の方向性のうち、5件のワード置き換えは実装済み。追加の決定として、以下の4件の問いかけを再度差し替える。○○ = 1-1で決定した課題。

| ワード | 観点 | 旧問いかけ（実装済み）               | 新問いかけ（決定）                                           | 型               |
| ------ | ---- | ------------------------------------ | ------------------------------------------------------------ | ---------------- |
| やる気 | どこ | どこでやると一番捗る？               | ○○という困りごとに対してモチベーションを上げる方法は？       | 差し込み型に変更 |
| 理由   | なぜ | なぜそんなに困るの？                 | そもそもなぜ○○に困っているの？                               | 差し込み型に変更 |
| 回避   | どう | その困りごとをしなくても済む方法は？ | ○○という困りごとをしなくても済む方法は？                     | 差し込み型に変更 |
| 立場   | 誰   | 誰に話すと楽？                       | 自分以外の気持ちになって考えてみたら考え方は変わるだろうか？ | 聞き取り型のまま |

- 楽しみ（どうやったら{issue}を楽しめるだろう？）は差し込み型として実装済み。今回変更しない。
- この決定により、{issue} を含まない問いかけは立場の1件のみになる。課題が空のときは雲に「決定した課題を確認できません」を出す既存挙動のまま。
- ジャンル分類による4組の再編、ジャンル名のUI表示は不採用。現行の観点別4組を維持する。
