本番リリース

GitHub の最新 develop 全体を ideaboost.dev に公開します。

前提を確認

初回の設定はこちら →
  • 公開する変更は develop にマージ済み対象のCIが成功。他の変更も含めて公開範囲を確認。
  • 進行中の公開・未記録の本番がないActions を確認。未記録なら先に回復。
  • ローカルは最新の developSkill・ローカル操作時。未コミットの変更がない。
  • gh auth status が通るSkill・ローカル操作時。GitHubの公開・記録権限がある。

公開方法を選ぶ

CODEX のチャット

Skill で公開

最新の develop を開いて操作

  1. 候補を表示$release

    前回との差分・説明・タグ候補を確認。起動だけでは公開されません。

  2. 説明を整える

    edit タイトルを「結果をテキストで保存」にして

    説明の編集では公開範囲は変わりません。

  3. 公開を指示release

    「これで公開して」でも実行。中止は cancel。

公開対象はGitHubのdevelop。ローカルの未コミット変更は含みません。SHA・PR番号の転記は不要。

この手順書を GitHub Pages へ公開

  1. docs/site/release-flow/index.html を編集し、develop向けPRを作る。
  2. PRの「Docs サイトプレビュー」で表示を確認する。
  3. developへマージ → Deploy docs site to GitHub Pages 成功 → 公開ページ を確認。
