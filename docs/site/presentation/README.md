# Idea Boost プレゼンテーション

`index.html` をブラウザで開くと、約10分29秒・全14枚のプレゼンが始まります。
インストール、ビルド、インターネット接続は不要です。

制作チームは「エンジニアファースト」。学生に「面白い内容だな」と興味を持ってもらうため、PRDをもとに「導入演出 → ローンチ動画 → タイトル → 必要とされるアイデアとは → 開発者の実体験 → デザインスプリント → Netflixの紹介事例 → 3フロー → 詳細ワークフロー → デモ動画 → 差別化 → 目指す状態 → 次の展望」の順に構成しました。
導入演出で期待感をつくってからローンチ動画を流します。導入演出とローンチ動画ではヘッダー・フッターを隠し、ページ全体を使って表示します。続く白背景のスライドでは文字を中心メッセージに絞り、Googleで生まれたデザインスプリントの考え方と、メイン画面を大きく紹介します。詳しい説明は `speaker-notes.md` の発表原稿で補います。

## 持ち運び

このフォルダを丸ごとコピーしてください。

- `index.html` — 14枚のスライド、操作、発表原稿
- `idea-boost-launch.mp4` — Idea Boostのローンチ動画（42秒・1920×1080・60fps・音声あり）
- `launch-poster.png` — ローンチ動画の再生前画像
- `design-sprint-individual-team.png` — 提供PDF p.23の引用図版（出典は画面と発表原稿に記載）
- `demo2.mp4` — 添付されたオリジナルのデモ動画（2分・1920×1080・60fps・無音）
- `demo-poster.jpg` — メイン画面と、デモの再生前画像
- `guide-detail.jpg` / `hints-detail.jpg` — デモから抜き出した実画面
- `company-logos/` — 6枚目の企業事例ロゴ（ローカル表示用）
- `speaker-notes.md` — 時間配分と読み上げ原稿、想定Q&A、PRDの対応箇所

動画と画像は相対パスで読み込みます。ファイル名と配置を保ってください。

## 発表時の操作

| 操作 | 方法 |
| --- | --- |
| 次・前のスライド | 左右の矢印キー、PageDown / PageUp、画面下の矢印 |
| 次のスライド | Space（ボタンや動画などの操作中を除く） |
| 最初・最後のスライド | Home / End |
| 指定のスライドへ | 画面下の13本の目次バー |
| 全画面 | 右上の全画面ボタン、または F。終了は Esc |
| デモ動画 | 「デモを再生」、または動画の標準コントロール |
| デモの区間へ移動 | 動画下の「再生位置を選ぶ」を開いてチャプターを選択。停止中は停止したまま移動 |
| 発表原稿 | `speaker-notes.md` を参照 |

配色はOSやブラウザの設定にかかわらず、白背景で表示します。
動画は自動再生しません。スライドを離れると一時停止し、再生位置は保持します。ローンチ動画には音声があります。
発表原稿は投影画面には表示しません。発表者は手元で `speaker-notes.md` を参照してください。

## 10分29秒で話すために

- 1枚目の導入で期待感をつくり、2枚目のローンチ動画は42秒です。
- 11枚目は、導入10秒とデモ2分の計2分10秒です。
- デモは基本的に通して再生し、要所に説明を重ねます。チャプターは練習や質疑で使えます。
- 10枚目でワークフローを説明してから、11枚目のデモで実際の操作を見せます。
- 開発者の実体験は共有された事実に基づきます。動画は操作の再現で、利用事例ではありません。
- 現在は実際の利用前です。13枚目の言葉は、利用者の感想ではなく、これから届けたい体験です。
- 配点、AIとの関係、所要時間などの詳細は、原稿末尾の想定Q&Aにあります。本編には含みません。
- 発表原稿は時間配分に合わせた目安です。自分の話す速さで通し練習をしてください。

内容の正本は `docs/prd.md` です。以前の `docs/presentation-structure.md` は今回の構成には使っていません。
