# Idea Boost プレゼンテーション

`index.html` をブラウザで開くと、約9分・全12枚のプレゼンが始まります。
インストール、ビルド、インターネット接続は不要です。

制作チームは「エンジニアファースト」。学生に「面白い内容だな」と興味を持ってもらうため、PRDをもとに「届ける価値 → 想定する4人の困りごと → 操作デモ → 学生にとっての価値 → 次のチームへの問いかけ」の順に構成しました。
全ページを白背景で統一し、文字は中心メッセージに絞っています。表紙は、添付デモから抜き出したメイン画面を大きく使っています。詳しい説明は、各スライド下部と `speaker-notes.md` の発表原稿で補います。

## 持ち運び

このフォルダを丸ごとコピーしてください。

- `index.html` — 12枚のスライド、操作、発表原稿
- `demo2.mp4` — 添付されたオリジナルのデモ動画（2分・1920×1080・60fps・無音）
- `demo-poster.jpg` — 表紙のメイン画面と、デモの再生前画像
- `guide-detail.jpg` / `hints-detail.jpg` — デモから抜き出した実画面
- `speaker-notes.md` — 時間配分と読み上げ原稿、想定Q&A、PRDの対応箇所

動画と画像は相対パスで読み込みます。ファイル名と配置を保ってください。

## 発表時の操作

| 操作 | 方法 |
| --- | --- |
| 次・前のスライド | 左右の矢印キー、PageDown / PageUp、画面下の矢印 |
| 次のスライド | Space（ボタンや動画などの操作中を除く） |
| 最初・最後のスライド | Home / End |
| 指定のスライドへ | 画面下の12本の目次バー |
| 全画面 | 右上の全画面ボタン、または F。終了は Esc |
| デモ動画 | 「デモを再生」、または動画の標準コントロール |
| デモの区間へ移動 | 動画下の「再生位置を選ぶ」を開いてチャプターを選択。停止中は停止したまま移動 |
| 発表原稿 | 画面下の「発表原稿」を展開 |

配色はOSやブラウザの設定にかかわらず、白背景で表示します。
動画は自動再生しません。スライドを離れると一時停止し、再生位置は保持します。
発表原稿を開くと投影画面にも表示されます。投影中は閉じ、手元では `speaker-notes.md` を参照してください。

## 9分で話すために

- 5枚目は、導入10秒とデモ2分の計2分10秒です。
- デモは基本的に通して再生し、要所に説明を重ねます。チャプターは練習や質疑で使えます。
- 6〜9枚目では、機能の操作を繰り返すより「なぜこの仕組みなのか」を伝えます。
- 4人のチームは説明用の想定です。動画は操作の流れを再現したもので、利用事例ではありません。
- 現在は実際の利用前です。11枚目の言葉は、利用者の感想ではなく、これから届けたい体験です。
- 配点、AIとの関係、所要時間などの詳細は、原稿末尾の想定Q&Aにあります。本編の9分には含みません。
- 発表原稿は時間配分に合わせた目安です。自分の話す速さで通し練習をしてください。

内容の正本は `docs/prd.md` です。以前の `docs/presentation-structure.md` は今回の構成には使っていません。

## 構成の参考

[Shopifyの製品プレゼンテーション記事](https://www.shopify.com/jp/blog/product-presentation)を参考に、価値を先に示す導入、学生の想定ストーリー、デモとの接続、平易な言葉、質疑への備えを反映しました。結びは次のチーム制作を想像してもらう問いかけです。
