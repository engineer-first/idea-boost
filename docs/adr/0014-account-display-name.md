# ADR 0014: 認証名から独立した共通の表示名

## Context

Googleプロフィール名のままで参加したい人と、仲間に見せる名前を変えたい人がいる。オーナーは、変更した名前を操作中のルームと次のルームへ引き継ぐことを希望した。初期の名前入力を促す案を取り下げ、複数ルームの同時利用は主要用途としない範囲へ絞った。

## Decision

認証名と別の共通表示名を本人の設定として保持する。未設定ならGoogleプロフィール名を使い、変更入力を強制・促進しない。どの入口から変更しても次の作成・参加へ引き継ぎ、ルーム内の変更はそのルームへ即時反映する。完了成果と保全済み履歴は当時の名前を残す。表示名の変更と本人確認・権限を分け、再ログインで本人の選択を失わないためである。

### 本ADRで決定しないこと

関数・通信形式・保存の具体手順と移行方法は、表示名のIssue仕様・開発規約へ委譲する。参照先はReferencesに示す。

## Consequences

良い影響は、名前を変えたい人だけが変更し、次のルームでも同じ名前を使えること。悪い影響は、共通設定の保存と参加中ルームの反映が一括確定できず、途中失敗への案内が必要になること。中立の影響として、同じ表示名でも本人は別であり、過去の成果は改名しない。全在籍ルームへの同時反映が主要用途になった場合に見直す。

2026-11-03に実コード・一次資料を照合。オーナーの採用した要求と実装の一致を確認した。

## Alternatives Considered

ルームごとの名前だけでは次のルームへ引き継げない。全在籍ルームへの即時配送は、複数同時利用を主用途としない確認に基づき対象から外した。
