# ADR 0006: 共有付箋の移動をRoomDOのtransactionとして確定する

## Context

移動途中の座標を逐次保存する方式では、取消時に戻せず、複数枚の位置と分類変更が部分的に確定する。通信応答を待ってから本人の表示を動かすと、遅延が操作の応答性を決めてしまう。応答喪失後にも、保存成功と未保存を区別する必要があった。

## Decision

本人の途中表示を確定した共有状態から分け、RoomDOで移動対象の位置・分類・成功記録を一括して確定する。一つの操作は全件成功か全件拒否とし、結果不明は同じ操作の保存結果で解決する。共有状態の権威と可視性を保ちながら、通信応答を待たない本人の操作を可能にするためである。

### 本ADRで決定しないこと

関数・通信形式・保存の具体手順と移行方法は、キャンバス操作の実装用詳細へ委譲する。参照先はReferencesに示す。

## Consequences

良い影響は、本人の表示を即応させつつ、位置と分類の部分保存を防ぎ、安全な逆操作の根拠を残せること。悪い影響は、競合制御、結果照会、操作記録の保持に永続化と保守の費用が増えること。中立の影響として、本人の途中表示は保存成功を意味しない。長期ルームで記録量が問題になる場合や、共有範囲・Undoの要求が変わった場合に保持と確定の方式を見直す。

2026-11-03に実コード・一次資料を照合。根拠未確認：実装または提案記録は確認できるが、オーナーがこの技術方針・比較理由まで採用した元発言は確認できない。実装済みであることだけではAcceptedにしない。

## Alternatives Considered

途中座標の逐次保存を複数枚へ拡張する案では全件取消と分類の一括確定を守れない。本人の表示を共有状態の真実にする案では認可がクライアントへ移る。これらは元のADRと実装PRに記録された技術比較であり、オーナーによる個別の選択承認は未確認である。
