# ADR 0008: 作成受付と回復情報の寿命を分ける

## Context

ルーム作成の再送を同じルームへ収束させる旧案は、要求と名前を期限なく保持していた。名前の二重保持を短期化し、タブ閉鎖後にも回復できるようにする必要があった。一方、成功の有無が不明な要求を削除して再作成を許すことはできなかった。

## Decision

作成を受け付ける期間と、作成済みの事実を照合するための情報の寿命を分ける。受付は発行時を基準とする固定24時間とし、再試行で延長しない。詳細を有限期間で整理しても、古い要求を新規作成として受理しない境界と、成立を照合できる最小情報を保つ。本人の控えをブラウザへ永続化し、回復の照会を新たな作成と分ける。永久に名前を保持せず、二重作成・復活の防止を維持するためである。

### 本ADRで決定しないこと

関数・通信形式・保存の具体手順と移行方法は、ルーム作成の運用仕様へ委譲する。参照先はReferencesに示す。

## Consequences

良い影響は、要求詳細の保持を短期化し、同じブラウザのタブ閉鎖後にも回復できること。悪い影響は、分散した成立事実、期限、削除を照合する複雑さが増すこと。中立の影響として、結果不明の照合情報やオフラインの控えには保持例外があり、全コピーの24時間消去は保証しない。受付期間の妥当性、結果不明の滞留、時計異常や保存情報の巻戻しが問題になったら見直す。

2026-11-03に実コード・一次資料を照合。根拠未確認：実装または提案記録は確認できるが、オーナーがこの技術方針・比較理由まで採用した元発言は確認できない。実装済みであることだけではAcceptedにしない。

## Alternatives Considered

要求ごとの永久墓標を増やす案では保存量が要求数に比例する。単に期限後の行を消す案では古い要求を再受理し得る。採用理由と時計・削除の具体方式は運用仕様と実装PRに残す。
