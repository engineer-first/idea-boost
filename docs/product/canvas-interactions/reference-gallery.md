# キャンバスの参考ギャラリー

[FigJam / Miroの画像・GIFを開く](https://www.figma.com/board/bpWlMnyv0Z9pvq7mMeQ0dj?node-id=37-267)。
ツールバー、選択、移動、文字編集、描画、Undoなどを20場面で比較するための資料です。
Idea Boostで採用する規則は[キャンバス操作仕様](../canvas-interactions.md)を参照してください。操作契約は[実装用詳細](details.md)を参照します。

## 見方

- カード名を開くと、FigJamの該当画像・GIFと短い説明へ移動します。
- 公式GIF、公式静止画、実機収録、文書だけの根拠を区別しています。静止画1枚は操作の過程を証明せず、GIFに見えないキー操作も観察済みとしません。
- 取得日は2026-10-04。公式素材の撮影日やUI版は不明な場合があり、旧UIや段階展開中のUIは個別に注記しています。
- 公式素材は各権利者の著作物です。出典付きの比較参照として使い、オープンな再配布ライセンスは確認していません。画像・GIFのバイナリはリポジトリに保存していません。
