# スクラム運用ドキュメント

Issue Type・作成フォーム・Project 状態・自動化の正本は[Issue と GitHub Project の運用](../issue-management.md)です。このディレクトリではスプリント期間と物理ホワイトボードとの連携だけを扱います。

## ドキュメント

| ファイル                                                       | 役割                       |
| -------------------------------------------------------------- | -------------------------- |
| [whiteboard-github-projects.md](whiteboard-github-projects.md) | 物理ホワイトボードの使い方 |
| [sprints.md](sprints.md)                                       | スプリント期間と管理理由   |

## 正本

- PBI、DemoGoal、Task、Bug、Spike、相談・要望の内容: GitHub Issue
- 進捗状態: [GitHub Project #3](https://github.com/orgs/engineer-first/projects/3)
- スプリント対象: GitHub Milestone
- ホワイトボード: チームで話すための短い見出しと会話中の並び替え

Issue 本文や受け入れ条件を Markdown と二重管理しません。スプリントの割当ては Issue 作成後に Milestone で管理します。
