# Idea Boost プレゼン構成

## 基本情報

- 発表時間: 9分
- 対象: 学生
- プロダクト: Idea Boost
- 発表形式: 聴衆参加とプロダクトデモを含む参加型プレゼン
- 更新日: 2026-09-12

## 発表の中心メッセージ

> Idea Boostは、アイデア出しに慣れていない学生チームを、課題整理からアイデア決定まで案内するWebアプリです。

現在はデザインスプリントを軸に利用検証を進めています。将来は、デザインスプリントだけでなく複数のアイデア手法をまとめ、チームの目的に合った方法を選べるサービスを目指します。

## 発表コンセプト

Idea Boostを説明するだけでなく、発表そのものを小さなアイデア出し体験にする。

冒頭で聴衆に10秒間、学生生活の不便を1つ考えてもらう。個人で考える時間を先に確保し、その後にIdea Boostの「個人ワーク → 共有 → 整理 → 決定」という設計につなげる。

聴衆に残したい印象は次のとおり。

- アイデア出しは、最初の進め方で結果が変わる
- Idea Boostは、自由なキャンバスではなくチームの道案内を提供する
- すでに学生に使ってもらう検証を進めており、今後は方法の選択肢も広げる

## スライド別の内容

### 1. 学生生活の小さな不便

表示する内容:

> 「もっと〇〇できたら」と思ったことを、10秒で1つ考えてください。

話す要点:

> 今、頭の中にはアイデアが浮かんだ人がいると思います。でも、チームでいきなり話し始めると、最初に発言した人の案に流れたり、考えていたけれど言えなかったりします。Idea Boostは、まず全員が考える時間を確保するところから始まります。

見せるもの:

- 10秒のカウントダウン
- 学生生活の身近な困りごとを想起させる写真または短い言葉

### 2. アイデア出しで止まる理由

学生チームで起きる課題を3つに絞る。

- 何から考えればよいか分からない
- 最初に話した人の意見に流れる
- 出た案を整理して決められない

話す要点:

> 学生チームに足りないのは、付箋を置く場所だけではありません。次に何を考えればよいか分かる進め方が必要です。

### 3. デザインスプリント

スライドタイトル:

> Googleで実践されたデザインスプリント

説明:

> デザインスプリントは、Googleで実践され、Google Venturesでスタートアップ向けに発展した、チームで課題に向き合い意思決定を進める方法です。Idea Boostは、この考え方を学生チームの「何を作るか決める」場面に合わせて再設計しています。

注意点:

- 「Google公式のアプリ」や「Googleの方法をそのまま再現」とは表現しない
- 本来のデザインスプリントにはプロトタイプ作成やユーザーテストまで含まれる場合がある
- Idea BoostのMVPは、学生が特に困る課題整理からアイデア決定までに焦点を絞る

出典:

- [Google Design: Sprinting Ahead](https://design.google/library/design-sprints)
- [Google Developers Blog: Design Sprints for Developers](https://developers.googleblog.com/design-sprints-for-developers/)

### 4. Idea BoostのMVP

表示する流れ:

```text
課題を出す
    ↓
課題を整理する
    ↓
問いに変える
    ↓
アイデアを出す
    ↓
1つに決める
```

説明:

- 課題整理: 解くべき課題を決める
- 問いの作成: 「どうしたら私たちは、もっと〇〇できるだろう？」に変える
- アイデア: 問いに対する解決策を出し、比較して決める

HMWは、専門用語を出す場合も「どうしたら私たちは、もっと〇〇できるだろう？」と説明してから使う。

### 5. プロダクトデモ

機能紹介ではなく、1つのチームが決定にたどり着く物語として見せる。

デモの流れ:

1. ルームを作成し、メンバーが参加する
2. 全員が個人専用付箋に課題を書く
3. 付箋を共有し、似た課題を整理する
4. 投票で取り組む課題を絞る
5. 課題を問いに変える
6. アイデアを出し、価値と実現可能性で整理する
7. 採用アイデアを1つ決める

重点的に見せる場面:

- 個人ワーク: 声の大きさに左右されず、全員が先に考えられる
- 共有と投票: 他の人の意見に引っ張られずに候補を絞れる
- 2軸評価: 価値と実現可能性を見ながら決められる

### 6. 初学者を支える設計

| 学生チームの困りごと       | Idea Boostの仕組み             |
| -------------------------- | ------------------------------ |
| 何をすればよいか分からない | ステップごとのガイドとタイマー |
| 意見が偏る                 | 個人専用付箋と個人ワーク       |
| アイデアが散らかる         | グルーピングと2軸マッピング    |
| なかなか決まらない         | ステルス投票と決定ステップ     |

まとめの一文:

> Idea Boostはアイデアを自動生成するアプリではなく、チームがアイデアを出し、整理し、決めるための進行を支援するアプリです。

### 7. 既存手段との違い

| 手段         | 主な役割                     | 初学者チームに残る課題               |
| ------------ | ---------------------------- | ------------------------------------ |
| Miro・FigJam | 自由に作業する場所           | 進め方を自分たちで設計する必要がある |
| ChatGPT      | 個人で考えを広げる相手       | チームで整理・投票・決定しにくい     |
| Idea Boost   | チームで決定まで進むための型 | 自由度をあえて絞っている             |

まとめの一文:

> Miroは自由に考えるためのキャンバス。Idea Boostは、何を考えればよいか分からないチームの道案内です。

### 8. 実利用と今後の展望

スライドタイトル:

> 学生チームで検証しながら、アイデア手法を広げる

現在:

> 1年生と3年生の学生に実際に使ってもらうため、利用検証を進めています。操作に迷わないか、全員が意見を出せるか、最後までアイデアを決められるかを確かめます。

検証で確認すること:

- ガイドを見て次の行動が分かるか
- 全員がアイデアを出しやすいか
- 課題整理からアイデア決定まで進められるか
- どのステップで迷うか

今後:

> デザインスプリントだけでなく、SCAMPERや逆転発想など、さまざまなアイデア手法をまとめます。チームの目的に合わせて、必要な考え方を選べるサービスに広げます。

将来の価値:

- アイデアを広げたい
- 課題を整理したい
- 視点を変えたい
- アイデアを比較したい

単に手法を増やすのではなく、チームの状況に合った手法を選べることを価値として説明する。

### 9. まとめ

話す内容:

> Idea Boostは、学生チームが考え、整理し、納得して1つに決めるための進行の型を提供します。まずはデザインスプリントで検証し、将来はさまざまなアイデアの出し方を選べるサービスを目指します。
>
> アイデアは、もっと自然に。
