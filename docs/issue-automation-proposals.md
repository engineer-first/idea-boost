# Issue 操作と自動化の改善案

状態の正本は [現行運用](issue-management.md)。自己アサイン・Draft PR 作成・レビュー依頼・Draft 復帰の連携は PR #339 で実装する。旧分類の廃止と18件の再整理は Project 側へ反映済み。

## 実装済みの操作

- `Assign yourself`: 着手可能な Task / Bug / Spike を作業中へ進める。
- 同じ Issue の Draft PR 作成: すでに担当者が決まっている作業も開始できる。
- レビュー依頼: 単一の直接対応 Issue をレビュー中へ進める。
- Draft 復帰: 自動更新の記録が一致する場合だけ作業中へ戻す。
- `Closes #番号` のある PR を `develop` へマージ: 対象 Issue を完了にする。Issue のクローズは GitHub 標準機能が行う。
- Status を完了にする: Project の標準 automation が Issue を閉じる。

条件・権限・競合・有効化時期は運用の正本を参照する。以下は今後の候補であり未実装。

## 次の候補

| 候補             | 人の操作・契機                                       | 効果・条件                                         |
| ---------------- | ---------------------------------------------------- | -------------------------------------------------- |
| 保存ビュー       | 「自分の作業」「レビュー待ち」「今スプリント」を開く | 状態・担当・Milestone で絞り、手動検索を減らす     |
| 成果確認待ち一覧 | 子 Task が全部完了                                   | PBI の受け入れ条件・デモ手順を提示し、人が確認する |

保存ビューは [GitHub のビュー管理](https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project/managing-your-views)を使う。

## 手入力と迷いを減らす案

- **親から作る**: PBI から Task / DemoGoal を作る操作で、親子関係・関連リンクを設定し、Milestone は親の値を初期候補にする。親が未割当なら勝手に現在のスプリントへ入れない。
- **状態名を操作に寄せる**: エージェントへ「#340 を始める」「レビューを依頼」「確認できたので完了」「今回は見送る」と依頼できるようにする。Issue と変更内容を短く示し、同じ情報を二度入力させない。
- **停滞は一覧で見せる**: 長く更新されていない作業、担当なし、PR がマージ済みでも成果確認が残る Issue を一覧にする。経過日数だけで状態を変えず、通知は新しい停滞や対応が必要な変化に絞る。
- **ホワイトボードから直接開く**: 付箋に Issue 番号と URL の QR コードを付ける。写真から読み取った配置は更新候補として提示し、曖昧な文字から GitHub の状態を確定しない。
- **作成の途中から再開**: PBI / DemoGoal 作成の各段階で URL を記録し、通信失敗時には既存 Issue への Project 登録・リンク設定から再開する。現状の作成スクリプトは再実行で重複し得るため、次の改善候補とする。

## 自動更新に共通して必要なこと

- 自動化ごとに「対象の Issue Type」「変更前の状態」「契機」「変更先」を限定する。`見送り` と `完了` を同じ close イベントから推測しない。
- 戻す操作を実装する前に、直前の自動更新と元の状態を記録する。手動更新後に遅れて届いたイベントで状態を上書きしない。
- Issue 単位で更新を直列化し、実行直前に状態・PR の対応関係を再取得する。同じイベントを再実行しても追加の変更が起きないようにする。
- PR 本文のマーカーやコメント本文だけを権限として扱わず、実行者の権限を確認する。
- 「更新した対象・理由・前後の状態」「スキップ理由」を実行結果から追えるようにする。手動で戻す手段も残す。

まず今回の操作連携を1スプリント使い、状態の手直し・誤更新・スキップ件数を確認する。その結果から保存ビューや成果確認待ち一覧を追加する。
